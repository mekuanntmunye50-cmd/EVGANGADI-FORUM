# Evangadi Forum

## Setup
1. Create the MySQL database/tables (see setup_db.sql) and copy `.env.example` to `.env`, then fill in values.
2. Backend: `npm install && npm start` (port 5500)
3. Frontend: `cd client && npm install && npm start`
   Optional: set `REACT_APP_API_URL` in `client/.env` for production.
